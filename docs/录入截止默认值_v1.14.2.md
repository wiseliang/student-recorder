# 录入截止默认值 v1.14.2

新建各项录入或恢复普通草稿，工作日志截止日期默认上海当天；学情一键录入、谈话、陪伴的已选周次默认延伸至学校当前周。保留草稿的起始日期、已选旧周与间隔、人员和内容，不加入未来周。新建一键录入默认第1周至本周，谈话/陪伴新建默认本周。

本次页面中手动改过日期或周次后不再反复覆盖；“选到本周”恢复自动跟随周次。前台跨上海零点更新自动截止日期，后台返回时检查当天，学校日历更新后采用官方周次。已生成预览、失败任务重试及总览明确带入的周次保留原范围，不自动扩大待提交任务。

旧名单属于其原周次。截止延伸后丢弃不匹配的旧名单缓存，要求重新读取新范围的学校名单和次数，再生成预览；不会用旧名单静默创建新范围任务。既有任务仍需本人核对和点击确认提交。

回归覆盖上海零点、各入口默认周、旧草稿延伸/非连续周/未来周剔除、日期恢复保留起始及内容，及完整浏览器中的三种学情入口、旧名单失效、手动修改、工作日志跨天、已有预览不变。待核实课程判定未在此版本修改。
