# v1.13.0 挂科学分与课程核对

学业管理新增挂科学分合计及排名入口，支持全部所带学生和指定专业。按挂科学分从高到低排序，未同步数据单列，支持导出。

统计截至所选学期：同一课程要求不因重复不及格累加；重修学分变化仍取第一次挂科时的课程学分；通过后不再累计。对应关系待核实的挂科暂保留，确认关联的重修/替代课通过后移除；缺失学分单列待核实。

旷考计入尚未通过的挂科学分，但没有补考机会，不进入补考核对或巡考名单，也不提示补考通过候选；允许核对重修通过记录。

待核实记录旁提供对应关系核对入口，进入对应课程卡片后自动显示原课程名与代码，无须重新选择。只有一个通过候选时自动建议替代课程，教师确认依据和适用范围后才建立关系，历史成绩保留并重新统计。
