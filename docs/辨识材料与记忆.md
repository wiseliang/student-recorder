# 辨识材料与记忆

工作台新增“辨识材料与记忆”。建立项目、核实资料或导入已完成的同模板完整版PPT，再生成完整版/考核版。选择“开始或继续背诵”即可在当前App内练习，无需安装或登录掌心刷题。

初次联网下载后，照片、记忆卡、轮次与评级队列均加密保存在本机。姓名和班级答案须展开后显示。不会/模糊/熟练分别安排约10分钟/1天/7天后复习；自评不是正确率。断网可评级并续背，联网点“同步最新资料与复习记录”。跨设备轮次冲突时保留本机，明确选择是否读取云端轮次。

默认只记姓名、班级和已确认班委情况。其他个人情况需在项目内主动开启。空白表示缺失，不推断政治、宗教、心理或学情。下载内容离线使用期限30天；导出的PPT需自行管理。兼容后台1.16.0与掌心刷题记忆服务0.21.0。

记忆核心来自 palm-quiz/web/student-memory.js，经其scripts/export-student-memory.mjs导出 src/utils/memoryCore.js；修改共同规则应从源重新导出。加密使用expo-crypto随机数与AES-GCM，Android密钥仅存SecureStore；图片包与小型评级队列分开写入，避免每次评级重写照片。

`npm test`与CI材料/离线浏览器回归使用合成数据。此版本不含不同版式PDF/OCR、已有独立刷题账号绑定；这两项作为后续扩展。
